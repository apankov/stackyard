# Инициализация MariaDB стека tokensale

Всё, что здесь лежит, MariaDB выполняет **один раз** — при создании пустого
тома `tokensale_mysql_data`. На уже созданном томе содержимое этого каталога
игнорируется, поэтому положить сюда файл задним числом недостаточно: нужно
удалить том (`./scripts/stack.sh purge tokensale`) и поднять стек заново.

Каталог намеренно не пуст: в compose он смонтирован в
`/docker-entrypoint-initdb.d`, и если каталога на хосте нет, docker создаёт его
**от root** — MariaDB получает пустой каталог и не применяет ничего.

Сейчас init-скриптов здесь нет. Если они нужны — положите сюда `*.sql` или
`*.sh` и пересоздайте том.
